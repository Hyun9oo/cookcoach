# CookCoach 레시피 문서

## 운영 원칙

- 재료, 수량, 예상 조리시간, 조리 단계, `도와주세요!` 상황과 해결 방법을 임의로 바꾸지 않는다.
- 레시피 수정 전 해당 원본 자료와 이 디렉터리의 문서를 함께 확인한다.
- 상세 원본이 확정되지 않은 메뉴에는 내용을 생성하지 않고 `TODO`를 남긴다.

## 현재 상태

- `DUO_RECIPES.md`: `cookcoach_recipes_duo.docx`에서 둘이서 메뉴 3종을 옮긴 상세 기준 문서
- `SOLO_RECIPES.md`: 확정 메뉴 조합만 기록, 상세 원본 확정 대기
- `GUEST_RECIPES.md`: 확정 메뉴 조합만 기록, 상세 원본 확정 대기

## 원본 충돌 메모

파일명과 프로젝트 설명은 `cookcoach_recipes_duo.docx`를 둘이서 최종 레시피 원본으로 지정하지만, 실제 Word 문서에는 혼자서 및 손님과 함께 메뉴의 상세 내용도 포함되어 있다. 이번 범위에서는 사용자가 명시한 최종 확정 범위에 따라 둘이서 3종만 상세 Source of Truth로 승격했다. 나머지 상세 내용의 확정 여부는 팀 확인이 필요하다.
