# CookCoach 프로젝트

## 서비스 정의

CookCoach는 사용자가 보유 재료를 확인하고 메뉴를 결정한 뒤, 실제 조리 중 생기는 문제까지 해결하면서 한 끼를 끝까지 완성하도록 돕는 모바일 우선 웹 앱이다.

핵심 가치는 단순한 레시피 추천이 아니다.

> 사용자가 무엇을 만들지 결정하고, 실제 조리 중 발생하는 문제까지 해결하면서 한 끼를 끝까지 완성하도록 돕는 것

## 핵심 흐름

`SCAN → PLAN → COACH → REVIEW`

- SCAN: 냉장고 또는 영수증 촬영과 재료 확인
- PLAN: 상황과 콘셉트 선택, 메뉴 추천 및 상세 확인
- COACH: 단계별 조리 안내와 `도와주세요!` 문제 해결
- REVIEW: 요리 완료 확인, 식사 기록과 요리 캘린더 반영

## 개발 기준

- 기존 `CookCoach_6.html` 디자인과 정상 작동 기능을 최대한 보존한다.
- Vanilla HTML/CSS/JavaScript를 유지한다.
- Netlify에 배포 가능한 정적 웹 앱으로 만든다.
- 스마트폰에서 실제 앱처럼 사용할 수 있는 흐름을 우선한다.

## 공모전 우선순위

과도한 기능 추가보다 다음을 우선한다.

1. 사용 흐름의 명확성
2. AI 코치의 역할 전달
3. 실제 시연 가능성과 안정성

대표 시연 메뉴는 규동이며 상세 기준은 `docs/demo/GYUDON_DEMO.md`를 따른다.
