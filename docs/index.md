# CookCoach 문서 목차

이 디렉터리의 Markdown 문서는 CookCoach 프로젝트의 지속적인 Source of Truth다. 작업 전 이 문서와 작업 주제에 해당하는 문서를 먼저 확인한다.

## 핵심 문서

- [PROJECT.md](PROJECT.md): 서비스 정의, 가치, 개발 우선순위
- [APP_FLOW.md](APP_FLOW.md): 최종 사용자 흐름과 촬영 분기
- [REQUIREMENTS.md](REQUIREMENTS.md): 확정 요구사항과 현재 범위
- [DECISIONS.md](DECISIONS.md): 변경 이력을 보존하는 결정 로그

## 레시피

- [recipes/index.md](recipes/index.md): 레시피 문서 운영 원칙과 상태
- [recipes/DUO_RECIPES.md](recipes/DUO_RECIPES.md): 최종 확정된 둘이서 레시피 3종
- [recipes/SOLO_RECIPES.md](recipes/SOLO_RECIPES.md): 혼자서 메뉴 조합과 상세 원본 TODO
- [recipes/GUEST_RECIPES.md](recipes/GUEST_RECIPES.md): 손님과 함께 메뉴 조합과 상세 원본 TODO

## 시연

- [demo/GYUDON_DEMO.md](demo/GYUDON_DEMO.md): 공모전 영상 및 실제 시연의 Golden Path

## 원본 우선순위

1. 원본 자료 (`CookCoach_6.html`, `cookcoach_recipes_duo.docx`)
2. 이 디렉터리의 Markdown 문서
3. 구현 코드의 축약 데이터 또는 화면 문구

원본과 Markdown이 충돌하면 원본을 우선하고 충돌 사실을 보고한 뒤 Markdown을 갱신한다.
