# 규동 Golden Path

규동은 CookCoach 공모전 영상 및 실제 사용자 시연의 대표 메뉴다. `둘이서 × 간단하게` 조합으로 진입한다.

## 데모 냉장고 기준

`docs/recipes/DUO_RECIPES.md`의 규동 원본을 기준으로 한다.

- 소고기 200g
- 양파 0.5개
- 계란 1개
- 밥 400g
- 쯔유 6T
- 미림 2T
- 설탕 1.5T
- 물 120ml
- 소금 및 후추 약간
- 와사비 선택

소고기는 Golden Path를 위한 필수 재료이며 데모 냉장고에서 빠지면 안 된다.

↓

↓

둘 다 건너뛴 경우
'데모 냉장고 사용하기'

↓

재료 확인
- 소고기 200g
- 양파 0.5개
- 계란 1개
- 밥 400g
- 쯔유 6T
- 미림 2T
- 설탕 1.5T
등

↓

상황
'둘이서'

↓

콘셉트
'간단하게'

↓

추천
'규동'

↓

메뉴 상세

↓

필수 재료 확인
- 부족 없음: 요리 시작 가능

↓

↓

↓

마이페이지 캘린더에는 실제 기록이 없을 때 최근 상대 날짜 기준 데모 식사 기록이 한 번 생성된다. 이 기록은 실제 규동 완료 기록을 덮어쓰지 않으며 같은 날짜의 복수 메뉴를 함께 표시한다.

## 회귀 테스트 기준

기능 수정 후 위 흐름 전체를 최소 1회 확인한다. 규동 Golden Path가 깨진 상태에서는 다른 기능 개발을 완료한 것으로 판단하지 않는다.

## Phase 2 필수 테스트

1. 냉장고 건너뛰기
2. 영수증 건너뛰기
3. 데모 냉장고 사용
4. 소고기 200g을 포함한 규동 재료 확인
5. 둘이서 → 간단하게 → 규동
6. 필수 재료 부족 없음 확인
7. STEP 1~6 각각의 `도와주세요!` 원본 일치 확인
8. STEP 6의 `요리 완성하기`로 REVIEW 이동
9. 식사 기록 후 오늘 날짜 선택
10. 실제 `규동` 메뉴 기록 표시
11. STEP 1의 다른 문제 직접 입력 후 공통 안내 표시, Bottom Sheet와 작성 질문 유지 확인
12. 규동 hero 파일 부재 시 placeholder, 파일 추가 시 공통 경로 반영 확인

일반 모드에서는 소고기를 삭제한 뒤 규동 상세에서 `소고기 200g이 필요해요.`와 비활성화된 시작 버튼을 확인한다. 소고기 200g을 직접 추가하면 시작 버튼이 다시 활성화되어야 한다.
